# Row-wise Residuals (`vmap_rows`)

Simulated-path collocation models frequently evaluate a scalar or small-vector equation independently across \(m\) states generated by a sequential path:

$$
r(\theta) = \big[\, g(x_s(\theta), \theta) \,\big]_{s=1}^{m} .
$$

Wrapping `g` with `jax.vmap` causes standard Jacobian assembly over \(m\) cotangents (or \(n\) tangents) to execute \(m^2\) (or \(m n\)) passes through `g`.

## How `vmap_rows` works

`vmap_rows` is implemented on JAX's public `HiPrim` primitive interface (`jax.extend.core.primitives.register_primitive`) with custom `jvp`, `transpose`, and nested `vmap` rules:

- During primal evaluation and plain directional `jax.jvp` calls (such as geodesic second directional derivatives \(D^2 r(\theta)[d, d]\) and parameter sensitivities \(D_p r(\theta, a, p)[\dot{p}]\)), `vmap_rows` runs ordinary `jax.vmap(g)` without materializing per-row Jacobians.
- Under `jax.linearize` (used during dense Jacobian assembly), `vmap_rows` computes each row's Jacobian \(G_s = \partial g(z_s) / \partial z_s\) once via per-row reverse-mode differentiation (`jax.jacrev`) and stores only those compact row gradients as linearization residuals. Subsequent basis tangents or cotangent pullbacks reduce to batched matrix-vector contractions against \(G_s\).

| Operation | `jax.vmap` | `vmap_rows` |
|---|---|---|
| Row passes per dense Jacobian (\(m < n\)) | \(m^2\) pullbacks | \(m\) pullbacks |
| Row passes per dense Jacobian (\(n \le m\)) | \(m n\) tangents | \(m\) pullbacks |
| Stored linearization state | Full batched forward intermediates of `g` | Compact row Jacobians \(G_s\) |

When per-row reverse-mode intermediates are themselves large, pass `chunk_size=k` to `@vmap_rows(in_axes=..., chunk_size=k)` so the per-row `jacrev` pass executes in chunks of size `k` via `jax.lax.map(..., batch_size=k)`. Pair this with `jacobian_chunk=c` on `LevenbergMarquardt` or `Newton` to bound peak memory along the outer path `scan` as well.

## Example

```python
import jax
import jax.numpy as jnp
from flax import nnx
from nlls_gram import LevenbergMarquardt, vmap_rows


@vmap_rows(in_axes=(0, 0, None, None, None, None))
def euler_residual(X, u, next_shocks, weights, policy, p):
    X_next = u + (1.0 - p["delta"]) * X[None] + next_shocks
    u_next = jax.vmap(policy)(X_next)
    return p["gamma"] * u - p["beta"] * (weights @ (price(X_next, p) + u_next))


def residual(theta, args, p):
    policy = nnx.merge(args.graphdef, theta)
    X, u = simulate(args.X_0, args.shocks, policy, p)
    r = euler_residual(X, u, args.next_shocks, args.weights, policy, p)
    return r / jnp.sqrt(r.size)


solver = LevenbergMarquardt(residual)
```

## Contract

- Row `s` depends only on slice `s` of mapped inputs (`in_axes != None`) and shared unmapped inputs (`in_axes=None`).
- Pass differentiated quantities as positional arguments (pytrees, dicts, tuples, Flax NNX modules, and integer or boolean arrays are all supported).
- Supports `out_axes=0` and optional `has_aux=True`, and composes with `jax.jit`, `jax.lax.scan`, and outer `jax.vmap`.
